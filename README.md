# Capybara Hat Party! 🎩🦫

A fun interactive website featuring adorable capybaras wearing 27 different funny hats.

Made with love for Angel ❤️

## Features
- **8 unique capybaras** — each with their own name, body color, and hat
- **27 hat types** — Top Hat, Party Hat, Crown, Sombrero, Wizard Hat, Cowboy Hat, Santa Hat, Viking Helmet, Propeller Cap, Ice Cream Cone, Mushroom, Donut, Floral Crown, and more
- **Click any capybara** to give it a new random hat
- **Dance mode** — make all the capybaras wobble
- **Add more capybaras** to grow the party

## How to Run
Just open `index.html` in a browser!

## Built With
- HTML5 Canvas for drawing
- Pure JavaScript, no dependencies
